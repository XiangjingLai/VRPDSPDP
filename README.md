# VRPDSPDP
This material contains the source code of algorithm, the benchmark instances, and the best solutions  for the following paper:
Zheng Gao, Fuqin Deng, Zhang-Hua Fu, Xiangjing Lai*, Qinghua Wu,A problem reduction based memetic algorithm for the vehicle routing problem with discrete split deliveries and pickups,  Computers & Operations Research, 182: 107106, 2025.
